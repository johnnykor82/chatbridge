# ChatBridge

**Локальный HTTP API к авторизованному ChatGPT для ИИ-агентов и приложений.**

ChatBridge — самостоятельный неофициальный шлюз, который управляет отдельным Chrome-профилем с действующей сессией ChatGPT, сохраняет диалоги и вложения, предоставляет HTTP API, потоковые события и историю запросов. Внешним агентам не нужно самостоятельно управлять браузером.

> **Независимый модуль.** ChatBridge можно использовать отдельно либо совместно с **Mac Control** — другим проектом, который предоставляет ИИ-агентам инструменты управления macOS по протоколу MCP. Установка одного проекта не требует другого.

**Статус:** экспериментальная версия для предварительного ознакомления. Программа прошла автоматические и практические испытания, но веб-интерфейс ChatGPT может изменяться. **Это не официальный API OpenAI.**

## Возможности

- **Диалоги и контекст:** создание сессий, продолжение существующих бесед ChatGPT, синхронизация сообщений.
- **HTTP и SSE:** асинхронные запросы, постоянные идентификаторы, возобновляемый поток событий, отслеживание инструментов и завершения.
- **Файлы любых типов:** передача изображений, аудио, PDF, Word, Excel, скриптов и других двоичных файлов; сохранение всех доступных вложений из ответов, в том числе **нескольких изображений или документов в одном ответе**.
- **Усилие рассуждения:** `low`, `medium`, `high` для каждого запроса, **по умолчанию High**. Выбранный уровень проверяется в интерфейсе ChatGPT.
- **Параллельная работа:** по умолчанию до 10 активных диалогов с очередью и последовательной обработкой сообщений внутри беседы.
- **Восстановление:** SQLite, сохранение состояния, отсутствие слепых повторов неопределённых запросов, самостоятельный запуск и восстановление Chrome.
- **Фоновый Browser API v1:** ChatBridge самостоятельно управляет Chrome/CDP и предоставляет внешним клиентам изолированные браузерные сессии, переходы, DOM, клики, ввод, скриншоты и файлы. Видимый фоновый режим не должен перехватывать фокус пользователя.
- **Работа с MCP:** ChatGPT может использовать подключённые инструменты, а ChatBridge — автоматически обрабатывать запросы подтверждений согласно своей конфигурации.

## Совместная работа с Mac Control

**Mac Control — отдельный проект, а не обязательная зависимость ChatBridge.** Они отвечают за разные функции:

| ChatBridge | Mac Control |
|---|---|
| Предоставляет доступ к диалогам ChatGPT через HTTP | Предоставляет ИИ-агентам возможности macOS через MCP |
| Хранит сообщения, контекст, файлы и результаты | Позволяет выполнять разрешённые команды терминала, читать и записывать файлы |
| Управляет авторизованным Chrome и очередью запросов | Поддерживает диагностику системы, работу со службами и автоматизацию процессов на Mac |
| Передаёт ответы и документы вызывающему приложению | Может выступать инструментом, который ChatGPT вызывает при выполнении задач |

Например, внешнее приложение обращается к ChatBridge, ChatGPT анализирует задачу и при необходимости вызывает Mac Control для работы с файлами или системой на Mac, после чего ChatBridge передаёт приложению результат и вложения.

**Репозиторий Mac Control:** [johnnykor82/mac-control-mcp-server](https://github.com/johnnykor82/mac-control-mcp-server).

## Установка на macOS

Для установки понадобятся macOS, Google Chrome, Git и Python 3. Установщик проверяет архитектуру Mac и выбирает подходящую сборку uv. Если [uv](https://docs.astral.sh/uv/) отсутствует, он предложит скачать его через официальный установщик Astral; если `astral.sh` недоступен, автоматически попробует загрузить официальный релиз uv с GitHub и проверить его контрольную сумму. Homebrew не требуется и не используется. uv устанавливается в отдельный каталог ChatBridge без изменения настроек shell, затем создаётся изолированное окружение Python 3.13. Если оба источника недоступны, установщик покажет ошибку и инструкции для ручной установки.

```bash
git clone https://github.com/johnnykor82/chatbridge.git
cd chatbridge
./install.sh
```

Создаются отдельная папка приложения, постоянный Chrome-профиль и пользовательский LaunchAgent с автозапуском и восстановлением после сбоя. Chrome запускается **в фоне**. Если ChatGPT ещё не готов, установщик в интерактивном Terminal дожидается управляемого профиля и предлагает открыть окно входа (`[y/N]`). Ответьте `y` и **войдите в ChatGPT вручную** в этом окне. При отказе или установке без терминала сервис остаётся установленным, а установщик печатает команду для входа позже. Перед её выполнением вызовите `POST /v1/browser/wake`, затем дождитесь, пока `/v1/system/status` покажет `browser.mode=managed` и `browser.state=running`; команда также доступна через `./install.sh doctor`. Если включена API-аутентификация, передавайте настроенный ключ при вызовах wake и status. Для установки не требуются Mac Control или ранее запущенный CDP-браузер.

Через пять минут без реальных браузерных операций ChatBridge останавливает принадлежащий ему Chrome и показывает `browser.state=idle`; профиль сохраняется. Новая браузерная операция запускает Chrome и ждёт его готовности. `/health`, `/v1/system/status` и `/ready` не будят браузер. В idle `/ready` возвращает HTTP 503 с `ready=false`, `chatgpt_authenticated=null` и `reason=browser_idle`. Окно, открытое вручную в управляемом профиле, тоже может закрыться при переходе Chrome в idle; перед повторным открытием окна входа вызовите `POST /v1/browser/wake`.

Адрес API по умолчанию: **http://127.0.0.1:8787**.

```bash
./install.sh status      # Состояние
./install.sh doctor      # Диагностика авторизации и браузера
./install.sh upgrade     # Обновление с возможностью отката
./install.sh uninstall   # Удаление службы с сохранением данных
```

Подробности: [Установка и обновление (EN)](docs/INSTALL.md).

## Пример HTTP API

```bash
# Создать сессию
curl -s -X POST http://127.0.0.1:8787/v1/sessions \
  -H 'Content-Type: application/json' \
  -d '{"title":"my-agent"}'

# Подставить session_id из ответа
curl -s -X POST http://127.0.0.1:8787/v1/sessions/SESSION_ID/messages \
  -H 'Content-Type: application/json' \
  -d '{"content":"Проанализируй архитектуру","reasoning_effort":"high"}'
```

Получить результат: `GET /v1/requests/REQUEST_ID`. Подписаться на события: `GET /v1/requests/REQUEST_ID/events`. Скачать вложение: `GET /v1/media/MEDIA_ID`.

Также доступен **частично совместимый** с OpenAI API маршрут `/v1/chat/completions`. Это не полная реализация официального API; его SSE может содержать окончательный ответ одним блоком.

Документация: [HTTP API (EN)](docs/API_REFERENCE.md) · [Вложения (EN)](docs/ATTACHMENTS.md) · [Изображения (EN)](docs/IMAGES.md).

## Безопасность и ограничения

В зависимости от настроек ChatBridge может автоматически разрешать ChatGPT использовать подключённые MCP-инструменты. Такие инструменты способны выполнять существенные действия с правами пользователя. Перед подключением терминала, файловой системы или других привилегированных средств ознакомьтесь с [описанием рисков (EN)](SECURITY.md).

ChatBridge использует авторизованный веб-интерфейс ChatGPT и зависит от его изменений. Доступность моделей, режимов мышления, типов файлов и лимитов определяется аккаунтом и возможностями ChatGPT. Установка на полностью чистый Mac и высокая нагрузка пока не прошли полный цикл приёмки. Не открывайте локальный API в недоверенную сеть.
